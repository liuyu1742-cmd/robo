# 公开数据集整理风险登记表

> 本文件对应图片第2段风险说明，并按“不自采，只查找公开网站/公开数据集”的口径更新。

## 总原则

1. 不把公开图片搜索结果直接等同于可训练数据集。
2. 不把数据集中相近标签直接等同于项目目标标签。
3. 每张图片或每个数据集都要记录许可证、来源链接和使用边界。
4. 如果来源只适合“证明有公开资料”，不能写成“模型已训练通过”。

## 风险1：材质类地板普通图片容易混淆

涉及对象：

- `wood_floor`
- `tile_floor`
- `marble_floor`
- `laminate_floor`
- `vinyl_floor`

风险说明：

普通图片里的地板材质经常靠纹理、光照和场景猜测；`laminate_floor`、`vinyl_floor`、`wood_floor` 视觉上尤其容易混淆。普通物体检测框不适合直接解决这类问题。

规避方式：

- 优先使用COCO-Stuff的地面像素级标签作为“地面区域/材质粗分类”证据。
- `wood_floor` 可映射到 `floor-wood`。
- `tile_floor` 可映射到 `floor-tile`。
- `marble_floor` 可映射到 `floor-marble`。
- `laminate_floor` 只能先作为 `floor-wood` 的子属性，不单独宣称已精确识别。
- `vinyl_floor` 只能先作为 `floor-other` 或材质属性，不单独宣称已精确识别。

## 风险2：窗户部件不是单独物体

涉及对象：

- `window_glass`
- `window_frame`
- `screen_window`
- `balcony_door`
- `window_sill`

风险说明：

窗玻璃、窗框、纱窗、窗台通常是“窗户/门窗结构的一部分”，不是像杯子、手机那样可独立抓取的单个物体。直接用普通目标检测框容易边界不清。

规避方式：

- 优先使用ADE20K这类带物体和部件分割的数据集作为结构证据。
- 用COCO-Stuff的 `window-other`、`door-stuff` 等作为粗结构证据。
- 交付时写“结构分割/部件标注”，不要写“普通物体检测已完成”。

## 风险3：儿童服装不是普通服装类别

涉及对象：

- `child_clothing`

风险说明：

Fashionpedia能覆盖服装、服装部件和属性，但“儿童服装”不是简单的服装类别，而是“服装本体 + 儿童属性”。如果只用普通 `clothes` 或 `shirt/pants` 标签，不能证明系统能区分儿童服装。

规避方式：

- Fashionpedia用于服装本体、部件和属性证据。
- Wikimedia Commons儿童服装分类可作为公开媒体候选。
- 最终需要人工记录“儿童属性”映射，不能把普通服装标签直接替代为儿童服装。

## 许可证风险

公开网站上的图片不一定都能训练或再分发。使用时按以下顺序处理：

1. 优先使用数据集官方许可明确的数据。
2. Wikimedia Commons逐文件检查许可证。
3. CC BY/CC BY-SA要保留作者、标题、来源、许可证。
4. 禁止使用仅NC、ND、fair use或许可证不明的图片作为训练样本。

## 交付边界

当前阶段做的是“公开来源查找和证据整理”。  
除非后续真正下载图片、登记来源、完成标注和复核，否则不能说“13类真实数据集已完成”。
