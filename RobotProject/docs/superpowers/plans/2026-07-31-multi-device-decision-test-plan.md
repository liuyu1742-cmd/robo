# 多设备协同决策与测试文档实施计划

## 任务 1：为协同规划建立失败测试

- 新建 `tests/test_multi_device_coordination.py`。
- 验证支持的就寝指令能被识别。
- 验证输出包含三台现有设备、24℃目标、20%灯光、关闭窗帘及无冲突结果。
- 验证高温和低温变化分别触发制冷/制热重新规划。
- 验证无关指令不会被协同模块误识别。

## 任务 4：建立并运行可复现测试工具

- 新建 `tools/run_decision_planning_benchmark.py`。
- 固定随机种子，从已审核的 VLA 82 模板中抽取两个不同 VLA 任务的物体。
- 每个用例运行 10 次，记录纳秒计时转换后的秒数。
- 运行多设备临时温度变化重规划。
- 写出原始 JSON 结果。
- 为每轮输出独立证据 JSON，并记录原始计时值与输出 SHA-256。
- 对原始结果执行结构和阈值检查。
