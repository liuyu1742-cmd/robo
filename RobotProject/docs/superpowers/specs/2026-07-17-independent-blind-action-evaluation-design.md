# 独立盲测动作解析评估设计

## 目的

建立能够严格区分“原始模型动作解析能力”和“受约束系统最终动作正确性”的独立盲测流程。该流程用于验证项目当前 15 个家庭服务任务下的动作解析能力，不把规则纠错后的结果误称为原始模型能力。

## 覆盖范围

- 正式任务数：15。
- 正式不重复物体数：123。
- 正式任务—物体操作关系数：138。
- 每条任务—物体操作关系由独立人员编写 3 条自然语言表达。
- 盲测总样本数：414 条。

测试单位是“任务—物体操作关系”，而不是仅按物体计数。相同物体在不同任务中的期望动作可能不同，必须分别验证。

## 人工盲测填写

导出的填写表每行包含匿名样本编号、任务场景、物体、目标位置和 `human_instruction` 空列；不包含标准动作序列。

每条关系生成三个独立变体编号。填写人员应采用自然口语、同义表达、省略表达或礼貌表达，且不参考项目的标准指令或动作标签。填写完成后，导入程序才以内部关系表关联隐藏的标准动作序列。

## 冻结与防泄漏

导入后的盲测 JSON 记录源 CSV 的 SHA-256 指纹、创建时间和样本数。评测时重新校验指纹；文件被改动、样本数不是 414、关系覆盖不完整、存在空指令或重复规范化指令时均拒绝评分。

完成盲测集冻结后，不能根据盲测错误增添关键词、修改解析规则、调整约束或重新选择样本；若确实改动模型或规则，必须生成新的盲测版本并保留旧报告。

## 两条互不混淆的评分线

### 原始模型动作解析率

模型以冻结盲测指令为输入，直接生成动作序列。不得使用标准答案回退、`action_constraints`、规则覆盖或人工修正。使用整条序列完全一致评分：步骤、顺序、动作参数和目标位置全部一致才计为正确。

输出指标为：

- `raw_exact_sequence_accuracy`
- 每任务原始整序列准确率
- 原始步骤、动词、参数准确率
- 遗漏、额外步骤、顺序错误率
- 95% Wilson 置信区间

只有该原始指标的点估计超过 90%，才可表述“原始模型动作解析率超过 90%”。若要求统计把握更强，则应同时要求 95% 置信区间下界超过 90%。

### 最终系统动作准确率

在保留同一份原始输出的基础上，允许执行 `action_constraints` 得到最终安全动作序列。此指标称为 `final_exact_sequence_accuracy`，反映可交付系统的结果，不等同于原始模型能力。

报告还应列出被约束修正的样本数量、修正原因和修正前后差异。

## 验收标准

1. 414 条样本、138 条关系、每条关系 3 条变体均完整。
2. 测试文件在运行前通过冻结校验。
3. 报告同时包含原始模型与最终系统两套指标，不允许相互替代。
4. 若 `raw_exact_sequence_accuracy >= 0.90`，可报告原始模型达到项目要求；否则仅报告最终系统结果。
5. 每项报告保留逐样本预测，便于复核，而不是仅保存汇总百分比。
