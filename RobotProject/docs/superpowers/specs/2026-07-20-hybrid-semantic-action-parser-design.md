# 混合语义动作解析器训练与独立验收设计

## 目标

将“自然语言指令 → 任务—物体操作关系 → 标准动作序列”的**原始混合语义系统**整序列准确率提升至 90% 以上。最终结论只以已经冻结的人工复测集 `datasets/human_only_independent_action_retest_414.json` 为准。

## 诚实的指标口径

本阶段的系统由两部分组成：

1. 可训练的中文语义分类器，从用户指令预测 138 条任务—物体操作关系之一；
2. 不查看盲测答案的标准动作规划器，根据分类出的关系输出该关系在正式目录中定义的动作序列。

该指标应称为“混合语义动作解析系统整序列准确率”，不是“纯 Transformer 从文本直接生成动作序列准确率”。模型原始输出不经过 `action_constraints` 安全纠正后评分；受约束系统分数仍单独报告。

## 数据隔离

- **冻结终测**：`datasets/human_only_independent_action_retest_414.json`，414 条人工填写指令、138 条关系；训练、调参、错误查看均不得读取其 `instruction` 或 `actions`。冻结时另存只含规范化文本 SHA-256 的 `datasets/human_only_final_instruction_hashes.json`；训练生成器只读取这份哈希清单进行重叠拒绝。
- **旧诊断集**：`datasets/independent_blind_action_test_414.json`，只用于历史错误分析；不得用于训练，也不得用于最终成绩。
- **训练语料**：从 138 条正式关系和公开的物体/操作同义词自动生成，单独保存为 `datasets/semantic_action_train.json`。生成器必须与两份盲测的规范化文本哈希清单做重叠检查；遇到重复则拒绝写入训练集。
- **开发验证集**：从训练语料按关系分层划出 20%，仅用于早停和模型选择，不作为最终验收。

## 模型与数据流

```text
用户日常指令
   ↓
字符级中文语义编码器（训练得到）
   ↓
关系分类：task + object + operation（138 类）
   ↓
正式目录查找该关系的标准动作序列
   ↓
原始混合系统动作序列（正式评分）
   ↓
可选安全动作约束（单独报告，不替代原始分数）
```

编码器采用不新增外部依赖的 PyTorch 字符 n-gram 特征 + 线性分类头：训练和运行都可复现；对未见措辞的泛化依赖于多样化同义词、语序、礼貌语和上下文模板，而不是单个关键词匹配。

## 训练语料

每个关系生成至少 40 条训练表达（目标至少 5,520 条），覆盖：

- 直接命令：“关掉阅读灯”；
- 日常上下文：“睡觉前把台灯关一下”；
- 礼貌请求：“麻烦帮我把杯子洗干净”；
- 省略主语/对象后的常见表达，但不在无法唯一确定时强行标注；
- 正反动作对：打开/关闭、拿取/放置、清洗/检查、浇水/养护。

训练集每个关系只包含该关系的真实任务、物体和操作；同一物体在不同任务中的样本必须保留不同关系标签。对本身缺少明确对象的表达，训练器应将其归入“需要澄清”样本，而不是编造动作。

## 运行安全与失败处理

- 分类置信度低于阈值，或前两类关系分差过小：返回自然语言澄清问题，不输出猜测动作。
- 关系预测存在但目录中无标准动作序列：报结构化目录错误，不调用约束层伪造通过。
- 动作约束只能在输出后生成“最终系统动作”，不得覆盖或提高“原始混合系统”分数。

## 训练与验收顺序

1. 生成训练语料并检查它不与两份盲测文本重复；
2. 训练字符 n-gram 关系分类器，在独立开发验证集上选模型；
3. 用旧诊断集做只读误差分析，必要时只扩充训练生成器，不读取冻结终测；
4. 固定模型、训练语料指纹和阈值；
5. 只运行一次冻结人工复测，并生成原始与受约束两份分数、95% Wilson 区间和逐条报告。

## 成功标准

1. 训练语料与两份盲测文本的规范化重叠数为 0；
2. 开发验证集至少报告关系准确率、动作整序列准确率、拒绝/澄清率；
3. 冻结人工复测的原始混合系统整序列准确率达到至少 90%，才更新对外状态为“达标”；
4. 若低于 90%，如实保留分数和错误分布，不以受约束分数替代；
5. 结果报告清楚标注系统是“可训练语义分类 + 标准动作规划”的混合架构。

## 非目标

- 不在本阶段将视觉模型、EPIC 视频特征或机械臂执行纳入该 90% 指标；
- 不重训练现有动作 Transformer 来冒充文本语义模型；
- 不读取、改写、补写或反向利用冻结人工复测集的指令内容。
