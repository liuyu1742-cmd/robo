# 语义动作解析：新样本扩充与助手自测设计

## 目标

改进“自然语言指令 → 任务—物体关系 → 标准动作序列”的混合语义解析器，并建立一个由助手填写的冻结自测集，用于开发阶段的回归验证。

本阶段不宣称独立人工泛化能力，也不覆盖或重跑已经完成的 414 条人工终测。

## 数据隔离

| 数据 | 用途 | 是否可训练 |
|---|---|---|
| `human_only_independent_action_retest_414.json` | 已完成的一次性人工终测 | 否 |
| `human_only_final_instruction_hashes.json` | 终测文本的不可逆哈希 | 仅用于查重 |
| 新增扩充训练集 | 学习日常表达与关系分类 | 是 |
| 新增开发集 | 选择模型与阈值 | 否 |
| 新增助手自测盲测集 | 模型固定后的自动化回归验证 | 否 |

新训练、开发和自测文本都必须与终测哈希清单无重合。训练文本与开发/自测文本之间也必须无重合。

## 新样本设计

每个当前“任务—物体操作关系”新增明确意图的中文表达，覆盖：

1. 口语省略：如“灯关了吧”“给花来点水”。
2. 礼貌请求：如“麻烦把电视打开”。
3. 原因和时间语境：如“睡前把阅读灯关了”“花有点干”。
4. 语序变化：如“这个杯子帮我洗一下”“洗一下这个杯子”。
5. 同义动词：如“关闭/关掉/熄灭”“清洗/洗一下/刷干净”。
6. 任务重叠物体的上下文：如火灾报警器在“安防检查”和“养护管理”中的不同说法。

禁止加入“处理一下”“弄一下”一类没有操作意图的模糊句子作为带标签训练样本。

## 模型与评测

仍使用字符 n-gram 可训练关系分类器；模型先预测 138 个任务—物体关系之一，再从当前标准目录检索相应动作序列。

开发阶段同时记录：

- 关系识别准确率；
- 原始整序列准确率；
- 约束后整序列准确率；
- 平均置信度与低置信度案例。

助手自测集在模型固定后才生成和冻结，报告标题固定为“助手生成自测”，不得写成“人工盲测”或用于证明真实用户场景达到 90%。

## 交付物

- 新训练、开发、自测数据及各自哈希清单；
- 改进后模型和训练报告；
- 助手自测报告；
- 状态文档中的证据等级与限制说明。

## 成功条件

1. 任何新文本均不与已锁定人工终测哈希重合。
2. 开发与助手自测均完整覆盖 138 个关系。
3. 所有报告清楚区分“开发/助手自测”与“独立人工终测”。
4. 不读取或利用旧人工终测的文本和答案进行样本设计、训练或调参。
